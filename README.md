Proyecto individual — Herramientas de Ciencias de Datos I

Descripción

Análisis descriptivo de la incidencia de lesiones del ligamento cruzado anterior (LCA) en deportistas según deporte, sexo y nivel competitivo, utilizando datos publicados por Beynnon et al. (2014) y Montalvo et al. (2019).

Estructura del repositorio

cod/: scripts de R y reporte elaborado en Quarto.

config/: archivos de configuración y documentación.

data/Data_Original/: bases de datos originales.

data/Data_Integrada/: base de datos integrada para el análisis.

info/: información y referencias del proyecto.

res/graficos/: gráficos generados.

res/tablas/: tablas de resultados.

res/informes/: versiones de informes.

Herramientas utilizadas

R, tidyverse, readxl, ggplot2, knitr y Quarto.

Reproducción del reporte

Abrir Proyecto_individual.Rproj en RStudio.

Verificar que estén instalados los paquetes necesarios y Quarto.

Abrir cod/Individual_Sanchez_HerramientasDatosI_2026.qmd.

Renderizar el documento a PDF.
